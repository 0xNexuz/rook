# Demo runbook

1. Open Rook and read the hero: “Markets move. Rook moves with them.”
2. In the live rule card, keep **NVDA / falls / 5% / BUY / $100**.
3. Select **Simulate**. Point out the visible `DETERMINISTIC SIMULATION` label and animated evaluation pipeline.
4. Select **Review permissions**. Show exactly what Rook may and cannot do, then adjust the total cap or expiry.
5. Select **Connect & activate**. If no injected wallet exists, demonstrate the honest unsupported state. With a wallet, approve Robinhood Chain Testnet (`46630`).
6. Open **My Rooks**. The strategy is marked active with zero executions and no invented receipt. Pause, resume, then revoke it.
7. Open **Market**. If the official API responds, inspect canonical asset deployments. If it does not, show the explicit unavailable state.
8. Open **Explore**, fork **Market Dip Buyer**, and verify that only configuration is copied before returning to Create.

No narration should be needed to understand Create → Simulate → Permission → Activate → Observe.
